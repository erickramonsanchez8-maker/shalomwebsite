# Shalom — Sabor y Paz

Sitio web público del restaurante en Ciudad Guzmán, Jalisco, México.

## Dirección creativa vigente
- Identidad: cálida, editorial y familiar; paleta fija #111111, #F7F5EF, #C9B8A6 y #2E3A33.
- Tipografías: Playfair Display y Montserrat.
- El servicio debe comunicarse como una experiencia del restaurante, no como una marca llamada “Brunch”. El titular principal es **“Lo mejor se comparte.”**; “Brunch” queda como descriptor secundario y solo donde sea funcional (horario, menú o solicitud).
- No anunciar Dinner, cenas ni servicios no confirmados.
- Acciones principales: reservar mesa y pedir a domicilio por WhatsApp.
- Datos sin confirmar se mantienen como “por completar” o “por definir”; no inventar precios, teléfono, dirección ni disponibilidad.
- El logotipo original debe usarse sin rediseñar, recolorear ni cambiar tipografía.

## Estado inicial
- Prototipo HTML autónomo creado con menú editable, carrito, formulario de reservación, ubicación y estado horario según America/Mexico_City.
- Pendiente integrar los archivos originales de logo y fotografías, configurar los datos reales y probar los flujos en navegador antes de publicar.
